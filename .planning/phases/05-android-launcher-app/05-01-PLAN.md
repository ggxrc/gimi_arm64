# Plan 05-01: Interface Android (GUI) e Gerenciador de Arquivos de Mods

## Objective
Criar o módulo da interface visual Android (GUI) e o gerenciador da biblioteca de mods na pasta `/sdcard/GIMI/Mods/`.

## Tasks

1. **Estrutura do Projeto Android App**
   - Criar o manifesto `AndroidManifest.xml` com as permissões de leitura/escrita no armazenamento (`READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE`, `MANAGE_EXTERNAL_STORAGE`).
   - Declarar o suporte a `arm64-v8a` para incluir a biblioteca nativa `libgimi_arm64.so`.

2. **Gerenciador de Mods (`ModManagerService`)**
   - Implementar escaneamento recursivo na pasta `/sdcard/GIMI/Mods/`.
   - Ler arquivos `.ini` de cada subpasta para identificar nome do mod, autor, e lista de recursos modificados.
   - Implementar sistema de ativação/desativação de mods (ex: renomeando pasta com sufixo `.disabled` ou mantendo estado no `gimi_active_mods.ini`).

3. **Interface Visual (Toggles e Seletor)**
   - Tela principal exibindo os mods encontrados em formato de lista com interruptores (toggles) ON/OFF.
   - Seletor de variante do jogo (Play Store, Galaxy Store, China, Bilibili) com detecção dos apps instalados no Android.
