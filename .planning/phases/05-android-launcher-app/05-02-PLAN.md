# Plan 05-02: Módulo de Injeção de Vulkan Layer sem Root (Shizuku API & ADB Manager)

## Objective
Implementar a integração com o Shizuku e comandos de sistema Android para ativar a Vulkan Layer (`libgimi_arm64.so`) e lançar o Genshin Impact automaticamente com os mods aplicados.

## Tasks

1. **Integração Shizuku (`ShizukuLayerInjector`)**
   - Verificar se o serviço Shizuku está em execução no aparelho (`Shizuku.pingBinder()`).
   - Solicitar permissão de acesso ao Shizuku se ainda não concedida.
   - Executar comandos de shell privilegiados via Shizuku:
     - `settings put global enable_gpu_debug_layers 1`
     - `settings put global gpu_debug_app <target_package_name>`
     - `settings put global gpu_debug_layer_app <launcher_package_name>`
     - `settings put global gpu_debug_layers libgimi_arm64.so`

2. **Launcher / Disparador do Jogo**
   - Botão **"Iniciar Genshin Impact"** no app.
   - Aplicar as configurações da Vulkan Layer via ShizukuInjector.
   - Lançar a `Intent` de inicialização do pacote do Genshin Impact correspondente (Play Store / Galaxy Store / China).

3. **Status & Logs em Tempo Real**
   - Exibir no app se o Shizuku está conectado e se a Vulkan Layer está ativada.
   - Fornecer botão "Desativar Mods / Restaurar Padrão" (`settings put global enable_gpu_debug_layers 0`).
