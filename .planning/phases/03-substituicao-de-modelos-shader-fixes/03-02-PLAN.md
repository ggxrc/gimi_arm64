# Plan 03-02: Adaptador de layout de atributos de vértices (DX11 para Vulkan)

**Phase:** Phase 3: Substituição de Modelos & Shader Fixes
**Requirement(s):** MESH-02
**Goal:** Implementar o adaptador de layout de atributos de vértices (`VertexLayoutAdapter`) para remapear strides, offsets e formatos de tipos de dados de entrada entre o paradigma DirectX 11 do 3dmigoto e o Vulkan ARM64.

## Context

Os arquivos de malha 3D (.buf / .txt) exportados para o 3dmigoto no PC seguem o padrão DirectX 11 (HLSL semantics e formatos DXGI). Ao injetar esses vértices no renderizador Vulkan no Android ARM64, os formatos de atributos (`VkFormat`), strides de memória e bindings precisam ser traduzidos para que a GPU interprete os dados de posição, normais, tangentes e coordenadas UV corretamente.

---

## Tasks

### Task 1: Tabela de Mapeamento de Formatos `DXGI_FORMAT` → `VkFormat`
- **Goal:** Criar utilitário de conversão de tipos de dados de formatos de vértices e texturas.
- **Files to create/modify:**
  - `include/mesh/dxgi_vulkan_format.h`
  - `src/mesh/dxgi_vulkan_format.cpp`
- **Details:**
  - Mapear os formatos de atributos mais comuns usados em mods 3dmigoto:
    - `DXGI_FORMAT_R32G32B32_FLOAT` (16) → `VK_FORMAT_R32G32B32_SFLOAT`
    - `DXGI_FORMAT_R32G32B32A32_FLOAT` (2) → `VK_FORMAT_R32G32B32A32_SFLOAT`
    - `DXGI_FORMAT_R16G16_FLOAT` (34) → `VK_FORMAT_R16G16_SFLOAT`
    - `DXGI_FORMAT_R8G8B8A8_UNORM` (28) → `VK_FORMAT_R8G8B8A8_UNORM`
    - `DXGI_FORMAT_R8G8B8A8_UINT` (30) → `VK_FORMAT_R8G8B8A8_UINT`
  - Função `VkFormat dxgi_to_vulkan_format(uint32_t dxgi_format) noexcept`.

### Task 2: Implementar `VertexLayoutAdapter`
- **Goal:** Classe que reconstrói descritores de binding e atributos de vértices para Vulkan a partir do layout original do mod.
- **Files to create/modify:**
  - `include/mesh/vertex_layout_adapter.h`
  - `src/mesh/vertex_layout_adapter.cpp`
- **Details:**
  - `struct VertexAttribute { uint32_t location; uint32_t offset; VkFormat format; }`
  - `struct VertexBinding { uint32_t binding; uint32_t stride; std::vector<VertexAttribute> attributes; }`
  - `class VertexLayoutAdapter`:
    - Converte definições de elementos de entrada do 3dmigoto para vetores de `VkVertexInputBindingDescription` e `VkVertexInputAttributeDescription`.
    - Garantir que o stride alinhado evite acessos não-alinhados que causam falhas de GPU em arquitetura ARM64 Mali/Adreno.

---

## Verification Criteria

1. Mapeamento de formatos `DXGI_FORMAT` para `VkFormat` retorna os enums corretos da especificação Vulkan.
2. `VertexLayoutAdapter` calcula os strides e offsets de memória corretamente para estruturas de vértices compostas (Posição + Normal + UV + Tangente).
3. Testes unitários com layouts de mods reais confirmam compatibilidade de dados.
