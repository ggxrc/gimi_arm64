# Plan 03-03: Executor de correções de shader e iluminação (Orfix/Txfix)

**Phase:** Phase 3: Substituição de Modelos & Shader Fixes
**Requirement(s):** FIX-01, FIX-02, FIX-03
**Goal:** Implementar o executor de correções de shader (`ShaderFixEngine`) para interceptar a criação de módulos de shader no Vulkan (`vkCreateShaderModule`) e aplicar as regras do `Orfix.ini` (iluminação/sombras) e `Txfix.ini` (transparência/UVs) via patching de SPIR-V.

## Context

Ao modificar modelos 3D em jogos como Genshin Impact, o renderizador original pode gerar artefatos visuais de iluminação, sombras deslocadas ou transparências quebradas. Os arquivos `Orfix.ini` e `Txfix.ini` do 3dmigoto contêm regras e shaders modificados específicos para corrigir esses problemas. O `ShaderFixEngine` intercepta a criação de shaders e injeta o bytecode SPIR-V corrigido em tempo de execução.

---

## Tasks

### Task 1: Interceptar `vkCreateShaderModule` no Vulkan Layer
- **Goal:** Exportar e implementar o hook de criação de shader module.
- **Files to create/modify:**
  - `include/graphics/vulkan_layer.h`
  - `src/graphics/vulkan_layer.cpp`
- **Details:**
  - Adicionar `PFN_vkCreateShaderModule CreateShaderModule` na `DeviceDispatchTable`.
  - Implementar `gimi_vkCreateShaderModule(device, pCreateInfo, pAllocator, pShaderModule)` em `vulkan_layer.cpp`.
  - Interceptar a chamada em `vkGetDeviceProcAddr`.

### Task 2: Implementar Hashing de Bytecode SPIR-V
- **Goal:** Calcular o hash xxHash64 do bytecode de shaders para identificação única.
- **Files to create/modify:**
  - `include/shaders/spirv_hasher.h`
  - `src/shaders/spirv_hasher.cpp`
- **Details:**
  - `uint32_t compute_spirv_hash(const uint32_t* code, size_t code_size_bytes) noexcept`.
  - Hashing ultra-rápido do buffer de uint32_t usando xxHash64 e truncando para 32 bits (compatível com 3dmigoto ShaderOverride hash).

### Task 3: Implementar `ShaderFixEngine` (Orfix & Txfix Executor)
- **Goal:** Motor de consulta à `ModDatabase` para substituição ou patching de SPIR-V.
- **Files to create/modify:**
  - `include/shaders/shader_fix_engine.h`
  - `src/shaders/shader_fix_engine.cpp`
- **Details:**
  - `class ShaderFixEngine`:
    - `bool process_shader_module(VkShaderModuleCreateInfo& create_info, std::vector<uint32_t>& patched_code_storage) noexcept`
    - Calcula o hash do bytecode SPIR-V.
    - Consulta `ModDatabase::shader_overrides`.
    - Se houver correspondência com regra do Orfix/Txfix:
      - Substitui `pCode` em `create_info` pelo SPIR-V corrigido armazenado em `patched_code_storage`.
      - Emite log de confirmação (`LOGI("ShaderFixEngine: applied Orfix/Txfix shader override for hash 0x%08X", hash)`).

---

## Verification Criteria

1. `vkCreateShaderModule` intercepta a criação de shaders sem falhas.
2. Hashing de bytecode SPIR-V produz hashes estáveis de 32 bits idênticos para os mesmos dados de shader.
3. Quando um hash de shader corresponde a uma regra do Orfix/Txfix na `ModDatabase`, o SPIR-V é substituído com sucesso antes de passar para o driver de vídeo.
