# Plan 04-01: Interceptação de Descriptor Sets e Uploads de Textura Vulkan

## Objective
Implementar a infraestrutura de rastreamento de texturas na Vulkan Layer. É necessário gerar hashes de textura a partir dos uploads (`vkCmdCopyBufferToImage`) e associar esse hash tanto à `VkImage` quanto à `VkImageView`, permitindo a interceptação futura no momento de bind (`vkUpdateDescriptorSets`).

## Tasks

1. **`ImageStateTracker` (Header & Impl)**
   - Criar `include/textures/image_state_tracker.h` e `src/textures/image_state_tracker.cpp`.
   - Implementar uma classe thread-safe para rastrear as relações:
     - `VkImage` → `hash` (32 bits, calculado na hora do upload).
     - `VkImageView` → `VkImage` (para transferir o conhecimento do hash para a view).
   - Implementar métodos de limpeza acionáveis durante `vkDestroyImage` e `vkDestroyImageView`.

2. **Interceptação de Uploads (`vkCmdCopyBufferToImage`)**
   - Adicionar o hook no `VulkanLayer`.
   - Ler os dados de pixel a partir do buffer fonte (`srcBuffer`) se a memória for mapeável para a CPU, ou armazenar instruções de cálculo assíncrono/deferido.
   - *Nota de MVP:* Por enquanto, podemos assumir que o buffer fonte é acessível e realizar o hashing via `XXH64`. Atribuir este hash à `VkImage` de destino através do `ImageStateTracker`.

3. **Interceptação de Views (`vkCreateImageView`)**
   - Adicionar o hook para `vkCreateImageView` na `VulkanLayer`.
   - Recuperar o `image` do `VkImageViewCreateInfo`.
   - Gravar no `ImageStateTracker` a relação `imageView` -> `image`.

4. **Interceptação de Binds (`vkUpdateDescriptorSets`)**
   - Adicionar o hook para `vkUpdateDescriptorSets`.
   - Iterar sobre `pDescriptorWrites`. Se o tipo for `VK_DESCRIPTOR_TYPE_COMBINED_IMAGE_SAMPLER` ou `VK_DESCRIPTOR_TYPE_SAMPLED_IMAGE`:
     - Consultar o hash original a partir do `imageView`.
     - Deixar um log debug pronto (`LOGD`) reportando que a textura com hash `X` está sendo vinculada.
   - (A substituição real ocorrerá no Plano 04-02).
