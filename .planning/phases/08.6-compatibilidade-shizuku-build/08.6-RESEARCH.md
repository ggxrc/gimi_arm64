# Phase 8.6: Compatibilidade Shizuku, Fallbacks & Arquitetura de Build - Research

## Executive Summary
Pesquisa técnica para suporte completo ao Android 16 (API 36) como Target SDK, Android 10 (API 29) como Min SDK, integração com Gradle 8.x moderno e comunicação IPC segura com Shizuku v13+.

---

## 1. Configuração de Target SDK 36 (Android 16) & Min SDK 29 (Android 10)

### Requisitos do Manifesto e Compilador
- **`AndroidManifest.xml`**:
  ```xml
  <uses-sdk
      android:minSdkVersion="29"
      android:targetSdkVersion="36" />
  ```
- **Termux Build Pipeline (`build_termux.sh`)**:
  - `aapt2 link` passa as flags `--min-sdk-version 29 --target-sdk-version 36`.
  - `javac` compila com `-source 17 -target 17` (compatível com o runtime Java 17/21 do Termux e AGP 8+).
  - `d8` converte para o formato DEX otimizado para Android 10+.

### Mudanças de Comportamento no Android 14 - 16 (API 33 - 36)
- **Receptores de Broadcast Dinâmicos (`registerReceiver`)**: Exige a flag `Context.RECEIVER_EXPORTED` para receptores que escutam transmissões de outros apps (ex: `moe.shizuku.api.action.BINDER_RECEIVED` do Shizuku Manager).
- **SELinux Hardening no Armazenamento**: O uso de APIs `java.io.File` nativas do Android Framework é necessário para contornar restrições FUSE em `/sdcard`.

---

## 2. Estrutura de Build Híbrida (Termux + Modern Gradle)

### Arquivos de Configuração Gradle (Estilo Moderno)
- **`settings.gradle`**:
  Definição de repositórios (Google, MavenCentral) e inclusão do módulo `:app`.
- **`build.gradle` (Raiz)**:
  Definição dos plugins `com.android.application` versão `8.2.2`.
- **`app/build.gradle` (Módulo App)**:
  - `namespace = "com.gimi.launcher"`
  - `compileSdk = 36`
  - `defaultConfig { applicationId = "com.gimi.launcher"; minSdk = 29; targetSdk = 36; versionCode = 1; versionName = "1.0.0" }`
  - Configuração de depósitos NDK/CMake para compilar `libgimi_arm64.so`.

---

## 3. Shizuku API 13 & Tolerância a Falhas IPC

### Ciclo de Conexão com o Binder
1. `registerShizukuReceiverSafe()`: Registra dinamicamente o `BroadcastReceiver` com `RECEIVER_EXPORTED`.
2. `queryShizukuBinderDirectly()`: Realiza a consulta síncrona em `content://moe.shizuku.manager.shizuku` para recuperar a interface `IBinder`.
3. `grantSecureSettingsViaShizuku()`: Executa `pm grant com.gimi.launcher android.permission.WRITE_SECURE_SETTINGS` via Shizuku ADB shell.

---

## Conclusion
A arquitetura proposta garante que o app funcione tanto no celular via script leve `build_termux.sh` quanto no PC via Android Studio com Gradle moderno, suportando do Android 10 (API 29) até o Android 16 (API 36).
