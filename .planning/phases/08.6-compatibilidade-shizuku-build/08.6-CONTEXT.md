# Phase 8.6: Compatibilidade Shizuku, Fallbacks & Arquitetura de Build - Context & Decisions

## Executive Summary
Esta fase consolida a infraestrutura de build e a compatibilidade do GIMI Launcher com o ecossistema Android moderno (Target SDK 36 / Android 16, Min SDK 29 / Android 10) e a API do Shizuku v13+.

---

## Locked Decisions

### 1. Arquitetura de Build Híbrida (Termux + Modern Gradle)
- **Leveza no Termux (`build_termux.sh`):** O script `build_termux.sh` é mantido como o executor nativo no dispositivo mobile (~5s de compilação via `javac` + `d8` + `aapt2` + `apksigner` + `cmake`).
- **Modern Gradle Setup:** Adicionar suporte oficial ao Gradle moderno (Gradle 8.5+, Android Gradle Plugin 8.2+), estruturado com configurações atualizadas e sem APIs/plugins obsoletos ou descontinuados.
- **Compatibilidade IDE:** O repositório poderá ser aberto tanto no Android Studio quanto compilado via Termux sem conflitos.

### 2. Shizuku & Injeção da Vulkan Layer (Sem Root)
- **Método Primário:** Injeção rootless via Binder do Shizuku v13+ utilizando `Shizuku.newProcess()` e concessão dinâmica de `WRITE_SECURE_SETTINGS`.
- **Target SDK 36 & Min SDK 29:** Configuração para compilação com suporte ao Android 16 (API 36) como alvo e compatibilidade mínima com Android 10 (API 29).
- **Registro Seguro no Android 14+ (API 33-36):** Invocação de `registerReceiver` com a flag `Context.RECEIVER_EXPORTED` para escuta da ação `moe.shizuku.api.action.BINDER_RECEIVED`, eliminando `SecurityException`.
- **Fallback ADB:** Exibição do comando `adb shell pm grant com.gimi.launcher android.permission.WRITE_SECURE_SETTINGS` para ambientes sem Shizuku.
- **Escopo Restrito:** Não haverá integração com comando `su` / Root nativo, preservando a diretriz de injeção não-destrutiva e rootless.

### 3. Diagnóstico e Tratamento de Incompatibilidades OEM
- **Detecção de Bloqueios de ROM:**
  - MIUI/HyperOS (Xiaomi): Diagnóstico visual para bloqueios provocados pela "Otimização MIUI".
  - Samsung Knox / Pasta Segura: Detecção de ambiente isolado Knox.
- **Painel de Diagnóstico na UI:** O Dashboard exibirá o status em tempo real do Binder do Shizuku, permissão `WRITE_SECURE_SETTINGS` e o valor atual de `gpu_debug_layers` em `Settings.Global`.
