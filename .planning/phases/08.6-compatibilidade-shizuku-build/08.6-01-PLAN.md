# Plan 08.6-01: Compatibilidade Android 16 (API 36) / Android 10 (API 29), Gradle Moderno & Shizuku IPC

## Phase Context
- **Goal:** Atualizar o ecossistema de build para Target SDK 36 (Android 16), Min SDK 29 (Android 10), estruturar os arquivos Gradle modernos para o Android Studio e refinar o IPC do Shizuku v13+.
- **Requirements:** [BUILD-01, LAUNCHER-02, COMPAT-01]
- **Target Files:**
  - `android/app/src/main/AndroidManifest.xml`
  - `build_termux.sh`
  - `settings.gradle`
  - `build.gradle`
  - `android/app/build.gradle`
  - `gradle.properties`
  - `android/app/src/main/java/com/gimi/launcher/MainActivity.java`

---

## Tasks

### Task 1: Atualizar Target SDK 36 & Min SDK 29 no Manifesto e Script Termux
- No `android/app/src/main/AndroidManifest.xml`, atualizar `<uses-sdk android:minSdkVersion="29" android:targetSdkVersion="36" />`.
- No `build_termux.sh`, atualizar o comando `aapt2 link` para incluir `--min-sdk-version 29 --target-sdk-version 36`.

### Task 2: Estruturar Projeto Gradle Moderno (AGP 8.2+ / Gradle 8.5)
- Criar `settings.gradle` no diretório raiz configurando `pluginManagement` e `dependencyResolutionManagement` com repositórios `google()` e `mavenCentral()`.
- Criar `build.gradle` na raiz aplicando o plugin `com.android.application` versão `8.2.2` sem `apply false` legado.
- Criar `android/app/build.gradle` com:
  - `plugins { id 'com.android.application' }`
  - `android { namespace 'com.gimi.launcher'; compileSdk 36; defaultConfig { applicationId 'com.gimi.launcher'; minSdk 29; targetSdk 36; versionCode 1; versionName '1.0.0' } }`
  - `compileOptions { sourceCompatibility JavaVersion.VERSION_17; targetCompatibility JavaVersion.VERSION_17 }`
- Criar `gradle.properties` ativando `android.useAndroidX=true` e `android.nonTransitiveRClass=true`.

### Task 3: Refinar Diagnósticos de IPC Shizuku no `MainActivity.java`
- Garantir que `registerShizukuReceiverSafe()` utilize `Context.RECEIVER_EXPORTED` em builds executados em Android 13+ (API 33-36).
- Confirmar que `grantSecureSettingsViaShizuku()` exibe mensagens claras de sucesso e erro ao interagir com o Shizuku.

### Task 4: Executar Build e Verificar Assinatura do APK
- Executar `bash build_termux.sh`.
- Verificar se `GIMI-Launcher.apk` é compilado, alinhado e assinado com sucesso (`✔ APK Signature Verified Cleanly!`).

---

## Verification Strategy
- **Build Termux:** Execução de `bash build_termux.sh` finalizando com código de saída 0.
- **Validação de Manifesto:** Inspecionar se `aapt2 dump badging GIMI-Launcher.apk` reporta `targetSdkVersion:'36'` e `sdkVersion:'29'`.
