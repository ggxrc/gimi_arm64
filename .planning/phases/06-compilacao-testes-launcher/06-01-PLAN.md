# Plan 06-01: Integração de Build Gradle NDK CMake e empacotamento do APK

## Objective
Configurar os arquivos de build do Android Gradle (`android/build.gradle` e `android/settings.gradle`) conectando-os ao `CMakeLists.txt` nativo para permitir a compilação automatizada da `libgimi_arm64.so` e geração do APK.

## Tasks

1. **`android/settings.gradle`**
   - Criar arquivo de configuração de projeto Gradle declarando o nome do módulo `GIMI-Launcher`.

2. **`android/build.gradle`**
   - Criar arquivo `build.gradle` com a extensão `com.android.application`.
   - Configurar a diretiva `externalNativeBuild.cmake` vinculada a `../CMakeLists.txt`.
   - Configurar a restrição de ABI para `arm64-v8a`.
   - Incluir dependências do AndroidX e Shizuku API (se aplicável).
