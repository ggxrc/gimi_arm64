# Plan 06-01: Script de Build Leve no Termux (AAPT2 + D8 + CMake + OpenJDK-21 + Keystore)

## Objective
Criar e aprimorar o script de build leve `build_termux.sh` e a estrutura de chaves `android/debug.keystore` para compilar a `libgimi_arm64.so`, compilar/empacotar recursos e código Java/Kotlin com `openjdk-21`, e gerar o `GIMI-Launcher.apk` diretamente no ambiente Termux (Linux ARM64).

## Tasks

1. **`android/debug.keystore`**
   - Garantir a presença de um `debug.keystore` determinístico na pasta `android/` para permitir assinatura do APK via `apksigner` sem requerer input interativo do usuário.

2. **`build_termux.sh`**
   - Atualizar e aprimorar `build_termux.sh` para:
     - Detectar e verificar ferramentas do Termux (`openjdk-21`, `cmake`, `clang`, `aapt2` / `aapt`, `zipalign`, `apksigner`, `ecj`/`d8`).
     - Baixar/armazenar em cache um `android.jar` (API 34/33) caso não esteja presente no ambiente.
     - Invocar o CMake para compilar `libgimi_arm64.so` (`arm64-v8a`).
     - Compilar os recursos Android (`android/app/src/main/res`) com `aapt2 compile` e `aapt2 link`.
     - Compilar os arquivos Java (`android/app/src/main/java`) com `javac` (definido para `openjdk-21`) e desugar/converter em `classes.dex` com `d8`.
     - Montar a estrutura do APK (`resources.ap_` + `classes.dex` + `lib/arm64-v8a/libgimi_arm64.so`).
     - Executar `zipalign` e assinar o pacote gerando `GIMI-Launcher.apk`.
