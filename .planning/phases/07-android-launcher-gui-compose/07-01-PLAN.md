# Plan 07-01: JNI Native Bridge e Estrutura Navigation Compose (NavGraph)

## Objective
Implementar a ponte de comunicação JNI entre Kotlin e a biblioteca C++ nativa `libgimi_arm64.so`, definir o modelo de dados `ModInfo` e criar a infraestrutura de navegação `NavGraph` com Jetpack Compose.

## Tasks

1. **JNI Native Bridge (`GimiNativeBridge.kt` & `gimi_native_bridge.cpp`)**
   - Criar `android/app/src/main/java/com/gimi/launcher/native/GimiNativeBridge.kt` declarando `external fun scanMods(path: String): Array<ModInfo>` e `external fun toggleMod(path: String, enable: Boolean): Boolean`.
   - Implementar a camada de binding C++ JNI em `src/launcher/gimi_native_bridge.cpp` chamando as funções do `ModManagerService` e `ShizukuLayerInjector`.
   - Atualizar `CMakeLists.txt` para incluir `src/launcher/gimi_native_bridge.cpp`.

2. **Modelo de Dados & ViewModels (`ModInfo.kt`, `DashboardViewModel.kt`, `ModManagerViewModel.kt`)**
   - Criar classe de dados Kotlin `ModInfo` (nome, caminho, isEnabled, iniCount, textureCount).
   - Implementar `DashboardViewModel` e `ModManagerViewModel` gerenciando os estados visuais com `StateFlow`.

3. **Estrutura Navigation Compose (`NavGraph.kt` & `ScreenRoutes.kt`)**
   - Definir as rotas no sealed class `Screen` (`Screen.Dashboard`, `Screen.ModManager`, `Screen.Settings`).
   - Implementar a função composable `GimiNavGraph` configurando as transições de tela.
