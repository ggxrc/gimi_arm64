# Plan 07-02: Interface Visual Compose (Dashboard, Mod Manager, Settings) & APK Integration

## Objective
Implementar as 3 telas visuais em Jetpack Compose Material 3 (Dashboard, Mod Manager e Settings), integrar com a `MainActivity` e validar a compilação do APK no Termux (`build_termux.sh`).

## Tasks

1. **Tela Dashboard (`DashboardScreen.kt`)**
   - Criar `DashboardScreen` em Compose com Material 3 Cards exibindo:
     - Card de status da Vulkan Layer (Ativo / Inativo).
     - Card de status do Shizuku / Permissão ADB sem root.
     - Seletor de pacote do jogo (`PlayStore`, `GalaxyStore`, `ChinaServer`, `Bilibili`).
     - Botão destacado de ativação/injeção.

2. **Tela Mod Manager (`ModManagerScreen.kt`)**
   - Criar `ModManagerScreen` com barra de pesquisa (`OutlinedTextField`), contador total de mods e `LazyColumn` exibindo os cards dos mods.
   - Cada card exibe o nome do mod, contagem de `.ini` e um `Switch` interativo para ativar/desativar (disparando `toggleMod`).

3. **Tela Settings (`SettingsScreen.kt`)**
   - Criar `SettingsScreen` permitindo alterar a pasta raiz de mods (`/sdcard/GIMI/Mods/`), visualizar informações da versão do aplicativo e logs.

4. **Integração com `MainActivity` & Build do APK**
   - Atualizar a `MainActivity` para inicializar a interface `GimiApp` em Compose.
   - Executar `bash build_termux.sh` para compilar os nativos e empacotar o APK `GIMI-Launcher.apk`.
   - Garantir que o APK e os testes de integração passem com 100% de sucesso.
