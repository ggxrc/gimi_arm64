# Plan 01-02: Implementação da camada de interceptação Vulkan Layer / EGL Dispatch Table

**Phase:** Phase 1: Engine de Interceptação Vulkan ARM64 & Infraestrutura Nativa
**Requirement(s):** HOOK-02, HOOK-03
**Goal:** Implementar a estrutura Vulkan Layer / EGL Dispatch Table para interceptar entrypoints gráficos nativos de forma 100% não-destrutiva e em memória.

## Context

O projeto exige suporte dinâmico a Vulkan e OpenGL ES sem modificar o APK ou arquivos originais do jogo. Este plano constrói o dispatcher de interceptação gráfica e os entrypoints de Vulkan Layer (`vkGetInstanceProcAddr`, `vkGetDeviceProcAddr`) e EGL Hook (`eglGetProcAddress`).

---

## Tasks

### Task 1: Camada Vulkan Layer Entrypoints e Dispatch Table
- **Goal:** Implementar entrypoints da especificação oficial Vulkan Layer API.
- **Files to create/modify:**
  - `include/graphics/vulkan_layer.h`
  - `src/graphics/vulkan_layer.cpp`
- **Details:**
  - Definir e exportar `vkGetInstanceProcAddr`, `vkGetDeviceProcAddr` e `vkNegotiateLoaderLayerInterfaceVersion`.
  - Construir a tabela de dispatch para armazenar os ponteiros de função originais obtidos do driver Vulkan do Android.
  - Redirecionar chamadas não modificadas de volta para o driver sem causar overhead.

### Task 2: Camada de Interceptação EGL / OpenGL ES Hook
- **Goal:** Suportar hooking transparente em jogos executados via OpenGL ES.
- **Files to create/modify:**
  - `include/graphics/egl_hook.h`
  - `src/graphics/egl_hook.cpp`
- **Details:**
  - Interceptar `eglGetProcAddress` para mapeamento dinâmico de extensões GLES.
  - Manter tabela de ponteiros originais da `libEGL.so` / `libGLESv3.so`.

### Task 3: Dispatcher de Gráficos Unificado (Graphics Dispatcher)
- **Goal:** Unificar a detecção em tempo de execução e o roteamento entre Vulkan e EGL.
- **Files to create/modify:**
  - `include/graphics/graphics_dispatcher.h`
  - `src/graphics/graphics_dispatcher.cpp`
- **Details:**
  - Classe `GraphicsDispatcher` encarregada de identificar qual API de renderização foi inicializada pelo aplicativo.
  - Registrar os hooks em memória RAM sem alterar arquivos ELF ou executáveis no disco (atendendo ao requisito HOOK-03 de injeção não-destrutiva).

---

## Verification Criteria

1. Verificar se a interface de Vulkan Layer exporta os símbolos de negociação Khronos exigidos.
2. Confirmar que a estrutura da Dispatch Table preserva a cadeia de carregadores (loader chain).
3. Garantir que todo o processo de interceptação é puramente em memória e não-destrutivo.
