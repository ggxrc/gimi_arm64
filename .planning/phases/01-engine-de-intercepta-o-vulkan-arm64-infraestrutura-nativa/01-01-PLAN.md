# Plan 01-01: Setup do projeto NDK, CMake e estrutura base C++20

**Phase:** Phase 1: Engine de Interceptação Vulkan ARM64 & Infraestrutura Nativa
**Requirement(s):** HOOK-01
**Goal:** Estabelecer a infraestrutura de compilação C++20 nativa do Android NDK direcionada para a arquitetura `arm64-v8a` e implementar o sistema de logging nativo.

## Context

Esta é a primeira etapa do projeto `gimi_arm64`. Precisamos configurar a estrutura de compilação CMake/NDK C++20 e garantir a inicialização limpa da biblioteca nativa `libgimi_arm64.so` com um sistema de logging robusto baseado em `android/log.h`.

---

## Tasks

### Task 1: Configuração do CMakeLists.txt e Toolchain Nativa
- **Goal:** Criar o script de build `CMakeLists.txt` configurado para NDK r26b+ com padrão C++20.
- **Files to create/modify:**
  - `CMakeLists.txt`
- **Details:**
  - Configurar versão mínima do CMake (3.22+).
  - Definir C++ standard como C++20 (`set(CMAKE_CXX_STANDARD 20)`).
  - Alvo: Biblioteca compartilhada `libgimi_arm64.so`.
  - Flags de compilação: `-O3 -Wall -Wextra -fvisibility=hidden`.
  - Linkar com bibliotecas do NDK: `log`, `android`.

### Task 2: Sistema de Logging Nativo (`logger.h` / `logger.cpp`)
- **Goal:** Implementar utilitário de logging envelopando `<android/log.h>`.
- **Files to create/modify:**
  - `include/utils/logger.h`
  - `src/utils/logger.cpp`
- **Details:**
  - Tag padrão: `gimi_arm64`.
  - Macros/funções: `LOGD(...)`, `LOGI(...)`, `LOGW(...)`, `LOGE(...)`.
  - Garantir suporte a formatação estilo `std::format` ou printf para fácil depuração em tempo de execução no Logcat.

### Task 3: Ponto de Entrada da Biblioteca Nativa (`main.cpp`)
- **Goal:** Criar a inicialização do módulo nativo ao ser carregado pelo processo.
- **Files to create/modify:**
  - `src/main.cpp`
- **Details:**
  - Implementar rotina de inicialização via `__attribute__((constructor))` ou `JNI_OnLoad`.
  - Emite log de confirmação de carregamento contendo versão da engine e suporte ARM64.

---

## Verification Criteria

1. Executar verificação de sintaxe e estrutura do CMake.
2. Garantir que os arquivos header e fonte C++20 estão organizados em `include/` e `src/`.
3. Validar se a biblioteca compila limpa para a arquitetura `arm64-v8a`.
